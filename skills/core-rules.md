# 內建升級規則（core-rules）

## 名稱

內建升級規則（core-rules）

## 用途

約束 AI 在 Minecraft 模組版本遷移時的行為，確保遷移不破壞模組本身。

## 適用時機

每次遷移任務自動載入（內建 Skill）。

## 內容

1. **不可破壞公開功能與設定語意**：遷移不得改變模組的公開行為、設定檔與資源語意；僅做版本遷移所需的格式轉譯。
2. **只做遷移轉譯**：不新增、不刪除、不「順手改進」任何需求性功能。
3. **保留風格**：保留註解、命名風格、程式碼風格與既有結構，除非新版 API 要求變更。
4. **不確定即標註**：遇到不確定的變更，在變更處以 `MC-MIGRATE-REVIEW: 原因` 註解標記，不得靜默猜測。
5. **只用目標版本 API**：使用目標版本 mapping 與 API，不得混用舊版 API。

## 使用限制

僅適用於版本遷移任務；功能開發請改用一般開發流程。
